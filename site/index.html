Fast local notes

Grouped notes, quick capture, rich editing, search, and SQLite-backed persistence.

Useful local templates

Reusable table and account-membership templates turn repeated records into editable note tables.

Built for the desktop

Electron shell, always-on-top behavior, optional Windows launch-on-login, compact launcher, and a panel designed to stay out of the way.

Current stack

Pragmatic technology, minimal operational cost.

Renyiqian is built around Electron, React, TypeScript, SQLite, Tailwind CSS, dnd-kit, electron-builder, and electron-updater. The current product line is local-only and does not require provider APIs, OAuth, accounts, or managed cloud infrastructure.

  • Electron + React + TypeScript
  • SQLite via better-sqlite3
  • dnd-kit for local drag ordering
  • Tailwind CSS styling
  • Windows installer and updater flow
